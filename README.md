# JavaScript Fundamentals: Array & String Methods Practice 🚀

This repository contains my initial practice exercises with **JavaScript Array and String methods**. It focuses on understanding how to manipulate data structures efficiently using built-in JS functions.

## 📌 Project Overview
This project is a collection of hands-on examples where I practice:
- Adding and removing elements from arrays.
- Extracting and modifying specific parts of an array.
- Cleaning and formatting string inputs (like emails and IDs).

## 🛠️ Methods Explored
### Array Methods
- `push()` & `pop()`: Adding/Removing items at the end.
- `shift()` & `unshift()`: Removing/Adding items at the beginning.
- `slice()`: Creating a shallow copy of a portion of an array.
- `splice()`: Adding or removing elements at any specific index.

### String Methods
- `toLowerCase()`: Standardizing email inputs.
- `toUpperCase()`: Formatting identification codes (e.g., PAN card).
